# Archery: Cupid Has Been Fired 🏹

An ACCT 411 browser game adapted for Streamlit Community Cloud.

## Files

- `app.py` starts the Streamlit page and embeds the game.
- `game.html` contains the HTML, CSS, and JavaScript for the playable game.
- `requirements.txt` specifies the Streamlit version used by the app.

## Controls

- **W** — aim higher
- **X** — aim lower
- **Spacebar** — shoot an arrow
- **R** — restart

Click inside the game first so it receives keyboard input. The game runs in the browser; the Python file only displays it.

## Version

Version 1.0 — initial Streamlit deployment version.

All targets and scores are fictional game content.
